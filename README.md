# Canvas Calculator 🖌️➗

A colorful calculator built with **Python Tkinter Canvas**, featuring circular buttons and custom styling.  
This project demonstrates how to use Canvas shapes and text bindings to create an interactive calculator GUI.

## ✨ Features
- Circular buttons drawn with `Canvas.create_oval`
- Custom colors for special buttons (`C`, `del`, `=`)
- Entry widget for displaying input/output
- Supports basic arithmetic operations (+, -, *, /, %, .)
- Clear (`C`) and Delete (`del`) functionality
- Error handling for invalid expressions

## 🚀 Getting Started

### Requirements
- Python 3.x
- Tkinter (comes pre-installed with Python)

### Installation
Clone the repository:
```bash
git clone https://github.com/your-username/canvas-calculator.git
cd canvas-calculator

Run the calculator 
```
python calculator.py

```
